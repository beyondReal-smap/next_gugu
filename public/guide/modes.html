게임 모드 6종 — 규칙과 추천 사용 순서

구구단은 이해보다 자동화가 목표라 노출 횟수가 결정적입니다. 구구 어드벤처는 같은 72개 식을 6가지 방식으로 반복하게 하고, 틀린 식의 출제 가중치를 올려 그 반복을 약한 곳에 집중시킵니다.

구구 어드벤처는 같은 72개 곱셈식을 서로 다른 6가지 방식으로 반복하게 합니다. 같은 식을 다른 형태로 만나야 기억이 특정 문제 형식에 묶이지 않기 때문입니다.

모드별 자세한 설명

학습 — 차근차근 기본기

압박 없이 또박또박 — 틀린 문제는 다시 나와요. 한 세션에 10문제. 시간 제한도 목숨 제한도 없습니다.

이럴 때 좋습니다: 처음 배우는 단, 또는 오답이 많이 쌓인 단을 차분히 정리할 때

스피드런 — 10문제 최고 속도

속도가 곧 점수! 빠르게 풀수록 XP가 올라가요. 10문제를 얼마나 빨리 푸는지 겨룹니다. 정답당 XP 보너스 4.

이럴 때 좋습니다: 이미 아는 단을 자동화(생각하지 않고 바로 답 나오는 수준)할 때

60초 챌린지 — 제한 시간 최대 점수

60초 동안 몇 문제나 풀 수 있을까요? 최고 기록에 도전! 60초 안에 맞힌 문제 수가 점수. 최고 기록이 저장됩니다. 단 선택 없이 2~9단 전체에서 무작위 출제.

이럴 때 좋습니다: 전체 구구단 실력을 한 번에 점검하고 기록으로 남길 때

서바이벌 — 기회는 단 3번

목숨 3개로 버티기! 틀릴 때마다 하트가 하나씩 사라져요. 목숨 3개로 시작해 틀릴 때마다 하나씩 잃습니다. 모두 잃으면 종료. 2~9단 전체에서 무작위 출제.

이럴 때 좋습니다: 속도보다 정확도를 끝까지 유지하는 훈련

빈칸 추리 — ? 에 들어갈 수는

곱셈을 거꾸로! 빈칸의 수를 찾으면 XP 보너스가 커요. 곱셈식의 한 자리가 빈칸으로 나오고 그 수를 찾습니다. 10문제, 정답당 XP 보너스 6으로 가장 높습니다.

이럴 때 좋습니다: 나눗셈으로 넘어가기 전 곱셈을 역방향으로 다룰 때

OX 퀴즈 — 맞으면 O, 틀리면 X

식이 맞는지 순간 판단! 헷갈리는 한 끗 차이를 가려내요. 제시된 곱셈식이 참인지 거짓인지 판단합니다. 10문제. 그럴듯한 오답이 섞여 나옵니다.

이럴 때 좋습니다: 6 × 7 = 48처럼 아슬아슬하게 틀린 답을 걸러내는 판별력 훈련

약한 구구단만 더 자주 나오는 이유

틀린 곱셈식은 출제 가중치가 올라가고(오답 1회당 가중치 +2.2), 직전에 나온 문제는 가중치가 0.15배로 낮아집니다. 결과적으로 약한 식을 더 자주, 방금 본 식은 덜 만나게 됩니다.

레벨·별·스트릭

  • 레벨과 XP — 정답 1개당 기본 XP를 얻고, 모드별 보너스가 더해집니다. 레벨 L에서 다음 레벨까지 필요한 XP = 60 + (L − 1) × 35
  • 마스터리 별 — 단마다 최대 별 3개를 모읍니다. 8개 단 전부 별 3개를 모으면 24개로 '올스타' 업적을 얻습니다.
  • 스트릭 — 하루라도 학습하면 스트릭이 1 늘어납니다. 3일·7일·30일 지점에 업적이 있습니다.

어떤 순서로 쓰면 좋은가

  1. 새로 배우는 단은 학습 모드로 정확도부터 잡습니다.
  2. 답이 안정되면 스피드런으로 속도를 올려 자동화합니다.
  3. OX 퀴즈로 값이 비슷한 오답을 구분하는 힘을 기릅니다.
  4. 빈칸 추리로 곱셈을 거꾸로 다뤄 나눗셈을 준비합니다.
  5. 마지막에 60초 챌린지와 서바이벌로 2~9단 전체를 점검합니다.
