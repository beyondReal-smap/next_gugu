🗑️ データ削除のご案内

アカウントおよびデータの削除

施行日：公開時に確定 · 2026年10月19日施行の韓国語版にもとづく翻訳です

九九アドベンチャーは、ログインせずにゲストとしてすべての学習機能を利用できます。 メールアドレスを連携していなければ、サーバーに保存される学習記録はないため、すべてのデータを利用者ご自身ですぐに削除できます。

ひと目でわかるご案内
  • ゲストとしてのみ利用した場合 — アプリで記録をリセットするか、アプリを削除すれば完了です。
  • メールアドレスを連携した場合 — アプリのプロフィール → 設定 → 記録を守る → アカウントを削除からすぐに削除できます。

1.端末内のデータの削除（すぐに）

学習記録・レベル・実績など、端末に保存されたデータは、次の2つの方法ですぐに削除できます。

  • アプリ内でのリセット：プロフィール → 設定 → 学習記録のリセット — 学習データがすぐに削除されます。
  • アプリの削除：端末からアプリを削除すると、端末内のすべてのデータもあわせて削除されます。

メールアドレスを連携していない場合はサーバーにコピーがないため、削除後に復元することはできません。

2.サーバーに保存されたアカウント・学習記録

保護者の方がメールアドレスを連携し、プレミアムの購入が確認されたアカウントでは、学習記録がサーバーに保存されます。 保存する項目は、プライバシーポリシー第1項をご覧ください。

  • アカウントの削除をご請求いただくと、アカウントとサーバーに保存された学習記録が削除されます。
  • 購入のレシートは、返金・監査への対応のため、アカウントとの連携のみを解除したうえで保存します。レシートには氏名・メールアドレスは含まれません。
  • アプリを削除しても、サーバーの記録は自動では削除されません。削除をご希望の場合は、下記の方法でご請求ください。

アプリの通知に関する情報

  • アプリの通知をオンにした場合、通知の送信に必要な情報（通知トークン、通知用インストール識別子、アプリのバージョン・言語、通知の受信設定、広告の受信同意の記録）がサーバーに保存されます。
  • アカウントを削除しなくても、プロフィール → 設定 → 通知で通知をすべてオフにすると、通知に関する情報はすぐに削除されます。アプリを270日以上使用しなかった場合も、自動で削除されます。
  • アカウントを削除すると、通知に関する情報と広告の受信同意の記録もあわせて削除されます。

3.アプリからすぐに削除

プロフィール → 設定 → 記録を守る → アカウントを削除

確認をもう一度押すと、アカウントとサーバーに保存された学習記録がすぐに削除されます。端末内の学習データと買い切りパスはそのまま残り、買い切りパスは購入を復元で再び利用できます。

4.メールでのご請求

お問い合わせメール：admin@smap.site

件名に「[九九アドベンチャー] アカウント削除のご請求」とご記入のうえ、アプリに連携したメールアドレスからお送りください。ご本人確認のための措置であり、そのほかに確認する情報はありません。

受付後、遅滞なく対応し、遅くとも30日以内に削除の結果をご返信します。

5.購入の記録

  • プレミアムの購入記録は、決済が行われた Apple App Store / Google Play のアカウントに保存され、各社のポリシーに従います。運営者はこの記録を削除できません。
  • 購入の復元はストアのアカウントに残った記録で行われるため、アカウントを削除した後も、同じストアのアカウントでプレミアムを復元できます。
