# 게임 생동감(juice) — 새 그림 없이 코드로 (C안, 2026-11-24 대표님 결정)

## 목표
아이 눈에 캐릭터가 "살아 있게" 보이게 한다. Unity 를 넣지 않고 지금 그림(PNG)의 크기·기울기·위치만 움직인다.

## 지금 있는 것 (건드리지 말고 그 위에 더함)
- 구구 계단: 착지 찌그러짐(`squash`, StairsStage.characterScale), 오답 흔들림, 자세 4장 교체, 0.28초 포물선 점프, 정답 반짝이(Sparkles)
- 구구 몬스터: 숨쉬기(squash 1±0.03)·위아래 통통(sin), 떨어지며 등장, 오답 흔들림·붉어짐, 처치 기절 그림 + 고리(Pop)
- 홈: 보물상자 통통(DailyMissionsCard), 누르면 작아지는 버튼(PressScaleStyle)

## 더할 것 (우선순위 순)
1. **구구 서 있기 숨쉬기** (계단): 서 있고 점프·흔들림이 아닐 때 세로 1±0.035 / 가로 반대로 1∓0.025, 주기 약 1.6초. 발이 발판에 붙어 있게 발 기준으로 늘린다(지금 drawCharacter 가 발 기준 scale 이므로 characterScale 에 곱하면 됨). 장신구도 같이 움직인다(이미 같은 변환 안).
2. **구구 점프 늘어남·기울기** (계단): 올라가는 동안 세로로 늘어남(최대 +18%, 가로 −10%, jumpT 0→0.5 에서 커졌다 줄어듦), 가는 방향으로 최대 10° 기울었다 착지 때 0. 착지 찌그러짐은 지금 것 그대로.
3. **착지 먼지** (계단): 착지 순간 발 양옆으로 작은 흰 원 4~6개가 0.3초 동안 퍼지며 사라짐. Sparkles 와 별개의 작은 풀(고정 개수, 매 프레임 할당 없음).
4. **몬스터 처치 타격감** (몬스터): 처치 순간 0.12초 화면 흔들림(카메라 x·y ±0.12유닛 감쇠) + 기절 그림이 첫 0.08초 하얗게 번쩍. 오답 흔들림과 겹치지 않게 처치에만.
5. **몬스터 가끔 깡총** (몬스터): 기다리는 동안 약 3초마다 한 번 작은 뜀(0.35초, 높이 0.25유닛, 뛰기 전 찌그러짐 → 공중 늘어남 → 착지 찌그러짐). 등장 낙하·오답·처치 중에는 안 함.
6. **홈 게임 카드 그림 숨쉬기**: 홈 구구 계단·구구 몬스터 카드 그림이 천천히 위아래 2pt·크기 1±0.02(두 카드 위상 다르게). 옷장 큰 구구 미리 보기도 같은 숨쉬기.

동작 줄이기(iOS `accessibilityReduceMotion`, Android 애니메이터 길이 배율 0)면 1·2·5·6 의 반복·장식 움직임은 끈다. 3·4 는 짧은 사건 반응이라 4 의 화면 흔들림만 끈다.

## 데이터 모양
- 움직임 공식은 순수 함수 한 곳(`Features/Games/Shared/Motion.swift`, Android `features/games/shared/Motion.kt`)에 상수와 함께 둔다:
  `breath(time, phase) -> (sx, sy)`, `jumpStretch(jumpT) -> (sx, sy)`, `jumpTilt(jumpT, dir) -> degrees`, `hop(t) -> (dy, sx, sy)`, `impactShake(left) -> (dx, dy)`.
  Stage 는 시간·사건만 들고 이 함수로 값을 얻는다. 화면(Scene)은 Stage 값을 그리기만.
- 먼지 풀은 Stage 안 고정 배열(Sparkles 처럼).
- 시간은 기존 엔진 time/dt(쉬는 창에서 멈춤)를 쓴다 — 쉬는 동안 숨쉬기도 멈춘다.

## 성공 기준
1. Motion 순수 함수 단위 테스트(경계값: jumpT 0·1 에서 늘어남 1·기울기 0, breath 범위, hop 시작·끝 0, shake 남은 시간 0 이면 0) + 기존 테스트 전부 통과.
2. 실제 화면: 시뮬레이터/에뮬레이터에서 짧은 간격 연속 캡처나 화면 녹화로 1(숨쉬기)·2(점프 중 기울기)·4(처치 흔들림)·5(깡총)·6(홈 카드)가 실제로 움직이는 것 확인. 프레임 비교 숫자(같은 위치 픽셀 차이 등)나 여러 장 캡처를 남긴다.
3. 프레임 성능: 게임 중 프레임 저하 없음(기존 대비 눈에 띄는 끊김 없음 — 녹화로 확인).
4. 동작 줄이기 켰을 때 반복 움직임이 멈추는 것(가능하면 화면, 아니면 테스트).
