# What's New — 2.2.0 (iOS build 19 / Android vc17)

## App Store (한국어)

기기를 바꿔도 학습 기록을 이어 쓸 수 있게 됐어요. 새로운 놀이 두 가지도 함께 들어왔어요.

기록 지키기
프로필에서 보호자 이메일을 연결하면 학습 기록이 안전하게 보관돼요. 비밀번호는 필요 없고, 메일로 받은 확인 코드 여섯 자리만 입력하면 끝이에요. 연결하지 않으면 기록은 종전처럼 기기에만 남아요. 기록 보관은 이용권을 구매한 계정에서 동작해요.

계정 삭제
프로필 > 기록 지키기에서 계정과 서버에 보관된 학습 기록을 직접 지울 수 있어요.

구구 레인
위아래로 길을 옮겨 장애물을 피하고, 문제가 나오면 정답이 적힌 길로 달려 들어가요.

구구 바구니
바구니를 좌우로 움직여 정답 열매를 받아요. 2단부터 천천히 시작할 수 있어요.

그 밖에 달라진 점
- 이용권을 이미 구매하셨다면 프로필 > 이용권에서 바로 복원할 수 있어요.
- 업적 칸을 넓혀 이름이 잘리지 않게 했어요.
- 정확도 추이 그래프에 0~100% 기준선과 현재 값을 넣어 한눈에 읽히도록 바꿨어요.
- 구구 점프가 더 경쾌해졌어요. 정답 세 개마다 속도가 한 단계씩 올라가요.
- 홈 화면을 놀이 방식별로 정리하고 글자 크기 위계를 다듬었어요.
