# What's New — 2.3.0 (iOS build 21 / Android vc19)

## App Store (한국어)

선생님 목소리가 문제를 읽어 주고, 구구단 표를 소리로 외울 수 있게 됐어요.

문제 읽어주기
새 문제가 나오면 선생님 목소리로 또박또박 읽어 줘요. 인터넷이 없어도 들을 수 있고, 프로필 > 설정에서 켜고 끌 수 있어요. 무음 모드에서는 들리지 않아요.

구구단 표 보기
학습 탭에서 단마다 책 버튼을 누르면 구구단 표와 외우는 요령을 볼 수 있어요. "소리로 외우기"를 누르면 한 줄씩 읽어 주고, 읽는 줄을 강조해 따라 외우기 쉬워요.

취약 문제 복습
자주 틀린 문제를 모아 한 번에 다시 풀 수 있어요.

주간 리포트
프로필에서 이번 주 학습한 날, 정답 수, 정확도, 푼 시간과 자주 틀린 문제를 한눈에 보고, 보호자를 위한 한마디도 받아 보세요.

설정
테마(기기 설정·라이트·다크), 효과음, 진동, 하루 목표, 학습 알림 시간을 한곳에서 바꿀 수 있어요.

그 밖에 달라진 점
- 틀리면 "35가 아니라 36이에요"처럼 무엇이 틀렸는지 알려 주고, 같은 단을 여러 번 틀리면 푸는 요령을 보여 줘요.
- 결과 화면에서 다시 볼 문제를 모아 보여 줘요.
- 풀던 중 닫기를 누르면 한 번 더 물어보고, 그만둬도 푼 문제는 기록돼요.
- 정답·오답 표시를 다듬어 문제가 흔들리지 않아요.
- 움직이며 놀기(구구 점프·레인·바구니)는 평생 이용권 기능이 되었어요. 이용권이 없어도 한 판에 3문제씩 체험할 수 있어요.
- 화면 읽기(VoiceOver) 안내와 버튼 크기를 다듬고, 아이패드 화면 폭에 맞췄어요.
