앱스토어(App Store)와 구글 플레이(Google Play)에 올릴 스토어 소개 이미지를 만들어줘.

## 앱 정보

- **앱 이름**: 구구 어드벤처
- **서브타이틀**: 매일 1분, 게임으로 배우는 구구단
- **타깃**: 초등학생(구구단 학습층) + 다운로드 결정권자인 학부모
- **한 줄 컨셉**: 3D 월드를 탐험하며 주민·보스와 구구단 대결을 펼치는 게임형 구구단 학습 앱. 서버 없이 매일 다시 들어오고 싶게 만드는 리텐션 설계(스트릭·데일리 골·레벨·마스터리)가 핵심.

## 핵심 기능 (캡션 소재)

1. **3D 어드벤처**: 새싹 들판(2단)→노을 사막(3단)→파도 해변(4단)→버섯 숲(5단)→눈꽃 설원(6단)→반딧불 늪(7단)→용암 화산(8단)→성(9단)으로 이어지는 지역맵. 보스를 이기면 다음 지역이 열림. 조이스틱으로 캐릭터(파란 캡슐)를 움직여 주민 NPC(토끼 로로 등)에게 다가가면 "대결하기" 프롬프트가 뜸.
2. **구구단 배틀**: 체력전 — 정답을 맞히면 상대 HP가 깎이고, 콤보가 쌓이면 데미지 증가. HP바·콤보 배지가 있는 대결 화면.
3. **게임 모드 6종**: 학습(자근차근 기본기) · 스피드런(10문제 최고 속도) · 60초 챌린지 · 서바이벌(기회 3번) · 빈칸 추리(? 에 들어갈 수) · OX 퀴즈.
4. **성장 시각화**: 홈의 데일리 골 링(오늘 정답 N/20), 스트릭(연속 학습 일수 🔥), 레벨/XP 바, 단별 별점 마스터리(2~9단 별 1~3개), 업적 17종.
5. **오답 복습 루프**: 틀린 문제는 즉시 정답 표시 후 가중 재출제, 세션 종료 후 "틀린 것만 다시 풀기".

## 브랜드 비주얼

- **컬러**: 메인 indigo `#6366F1`(강조 `#4F46E5`), 포인트 amber `#FBBF24`, 배경 slate-50 `#F8FAFC`, 텍스트 진네이비. 성공 green, 위험 red는 절제.
- **앱 아이콘**: indigo 그라데이션 배경 위 3×3 흰 타일 그리드(숫자 2·4·6/3·×·6/4·8·9), 중앙 타일만 노란색 × 기호에 -6° 기울임. 이 타일 모티프를 배경 그래픽에 재활용해도 좋음.
- **톤**: "차갑지 않은 모던". 유아용 파스텔·이모지 남발·토이 폰트 금지. 볼드한 둥근 산세리프(SUITE 계열), 넉넉한 여백, 8pt 그리드, 카드 UI. 게임의 즐거움은 3D 월드 컷과 카피로 전달.

## 만들어야 할 산출물

### A. App Store 스크린샷 프레임 (1320×2868, 세로) — 6장
스크린샷을 그대로 올리지 말고, 각 장을 **프로모 프레임**으로 감싸줘:
- 상단에 큰 한국어 헤드라인(+작은 서브카피), 그 아래 iPhone 목업에 스크린샷 삽입
- 배경은 브랜드 컬러 그라데이션 또는 타일 모티프 패턴, 장마다 톤 변주(홈=indigo, 어드벤처=green 계열 허용, 배틀=energetic)
- 헤드라인 카피 초안(자유롭게 다듬어도 됨):
  1. 홈 — "매일 1분, 게임 한 판" / 스트릭·데일리 골로 습관이 돼요
  2. 3D 월드 — "구구단이 모험이 된다" / 8개 지역을 탐험해요
  3. 인카운터/배틀 — "주민과 구구단 대결!" / 정답으로 콤보를 터뜨려요
  4. 세션 — "빠르게 풀고, 바로 피드백" / 틀린 문제는 다시 나와요
  5. 학습 탭 — "6가지 게임 모드" / 스피드런부터 OX 퀴즈까지
  6. 프로필 — "성장이 눈에 보여요" / 레벨·별점·업적 17종
